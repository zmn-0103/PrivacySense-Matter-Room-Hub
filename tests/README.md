# Tests

此目录保存传感器、状态机、BLE commissioning、Wi-Fi 重连、Matter 状态同步和异常场景的测试用例与证据。

## 测试矩阵

每个测试用例按以下格式记录。测试结果存放在 `tests/evidence/` 目录下。

### 证据文件命名

```
tests/evidence/<test_id>_<version>_<date>.md
```

示例：`T01_v0.1_20260715.md`

### 证据文件内容要求

每个证据文件包含：
- 测试 ID 和标题
- 固件版本号
- 硬件版本号（开发板版本、模块批次）
- 前置条件
- 执行步骤
- 期望状态
- 实际结果
- 结论（PASS / FAIL / BLOCKED）
- 串口日志摘要（脱敏：移除 Wi-Fi 密码、Matter payload）
- 照片或视频引用（可选，文件存放在本地不提交，在证据文件中引用文件名）

## 证据目录

测试证据存放在 `tests/evidence/` 目录。该目录在 `.gitignore` 中被白名单排除（可提交）。

提交到版本控制的证据文件要求：
- 文件格式：Markdown（`.md`），不接受 `.log` 原始文件。
- 脱敏：移除 Wi-Fi 密码、Matter setup payload、私钥、真实 IP 地址。
- 日志摘要：只保留关键状态变化和时间戳，不提交完整串口输出。
- 照片/视频：不提交二进制文件，在 Markdown 中引用文件名和存放位置。

## 测试执行优先级

| 优先级 | 测试 ID | 说明 |
|---|---|---|
| P0（阻塞发布） | T03, T04, T05, T08, T12, T14 | 核心功能和关键异常恢复 |
| P1（重要） | T01, T02, T06, T07, T09, T10, T15, T19 | 误触发、传感器恢复、网络恢复、配网 |
| P2（建议） | T11, T13, T16, T17, T18 | 配置损坏、watchdog、模式切换、告警 |
| P3（长期） | T20 | 稳定性 |
