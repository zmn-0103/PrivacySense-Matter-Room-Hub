# R11 雷达配置保存测试

## 前置条件
- 固件：含 V1.09 命令模式支持（`ld2410c_core_exec_transaction` / `ld2410c_exec_cmd`）
- 使用 `idf.py flash monitor` 刷写并观察日志
- 如无可用的雷达模块，此测试延期至硬件就绪

## 测试步骤

### 1. 读取当前配置
固件通过 `ld2410c_core_exec_transaction()` 执行完整事务：
使能配置（0x00FF）→ 读取参数（0x0061）→ 结束配置（0x00FE）

观察日志确认三阶段 ACK 均成功。

### 2. 修改并保存
通过 `ld2410c_write_basic_params()` 写入参数，例如将无人延时设为 30 秒：
```
发送：FD FC FB FA 14 00 60 00 00 00 08 00 00 00 01 00 08 00 00 00 02 00 1E 00 00 00 04 03 02 01
     (长度=20, cmd=0x0060, 三组参数: 最大运动距离门8, 最大静止距离门8, 无人时间30s;
      帧长=cmd(2)+3×参数字(6)+3×参数值(12)=20=0x0014, V1.09 §2.2.3)
```

### 3. 断电重启雷达
断开雷达 VCC 供电，等待 10 秒后重新上电。

### 4. 重新读取配置
重复步骤 1，确认修改后的参数值保持不变。

### 5. 恢复原值
将参数改回原始值，断电重启后重新读取验证。

## 期望结果

| 步骤 | 期望 |
|---|---|
| 读取初始配置 | 三阶段 ACK 均成功，返回有效参数值 |
| 修改参数 | 写入 ACK status=0x0000 |
| 断电重启后读取 | 修改的参数保持 |
| 恢复原值后读取 | 恢复为原始值 |

## 通过标准
- 使能配置（0x00FF）→ 读取/写入（0x0061/0x0060）→ 结束配置（0x00FE）完整事务成功
- 断电重启后配置保持
- 配置修改后雷达恢复正常模式，仍可上报数据
- 日志无 I2C/UART 超时或协议错误

## 协议参考
- 命令帧：`FD FC FB FA [len_LE] [cmd_LE] [data...] 04 03 02 01`
- ACK 帧：`FD FC FB FA [len_LE] [cmd|0x0100_LE] [status_LE] [data...] 04 03 02 01`
- 官方协议："LD2410C 串口通信协议 V1.09.pdf"
